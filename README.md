# award-travel

A roame.travel-style flight search app. Searches **cash fares** via flight APIs and
finds **award (points/miles) availability** by integrating the `find-cheap-award-flights`
skill (Seats.aero Partner API). Built with Next.js.

Scope: search + user accounts + availability alerts.

> 🚧 Planning stage — design spec and implementation plan in progress.
